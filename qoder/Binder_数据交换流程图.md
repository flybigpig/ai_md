### 阶段 4：构建事务并入队

```
═══════════════════════════════════════════════════════════════════════════════════
  阶段 4: 构建 binder_transaction 并入队到目标
═══════════════════════════════════════════════════════════════════════════════════

  ┌─ 新建 binder_transaction ─────────────────────────────────────────────────────┐
  │                                                                                │
  │  ┌──────────────────────────────────────────────────────────────┐              │
  │  │  binder_transaction                                        │              │
  │  │  ┌────────────────────────────────────────────────────────┐ │              │
  │  │  │ from_proc  ──────▶ proc_A (Client)                    │ │              │
  │  │  │ from_thread ─────▶ thread_T1 (Client 调用线程)         │ │              │
  │  │  │ to_proc ─────────▶ proc_B (Server)                    │ │              │
  │  │  │ to_thread ───────▶ thread_T2 (Server 工作线程) 或 NULL │ │              │
  │  │  │ buffer ──────────▶ binder_buffer (在 proc_B 中分配)   │ │              │
  │  │  │ data_size = N                                        │ │              │
  │  │  │ offsets_size = M                                     │ │              │
  │  │  │ priority = current->normal_prio                      │ │              │
  │  │  │ debug_id = 42                                        │ │              │
  │  │  └────────────────────────────────────────────────────────┘ │              │
  │  └──────────────────────────────────────────────────────────────┘              │
  │                                                                                │
  └────────────────────────────────────────────────────────────────────────────────┘

  ┌─ 入队过程 ─────────────────────────────────────────────────────────────────────┐
  │                                                                                │
  │  1) 设置事务链（记录调用关系，用于回复时找到原调用者）                              │
  │                                                                                │
  │     thread_T1.transaction_stack ──▶ new_transaction                            │
  │     new_transaction.from_thread = thread_T1                                    │
  │                                                                                │
  │  2) 将事务加入目标的 todo 队列                                                   │
  │                                                                                │
  │     如果指定了 to_thread:                                                       │
  │     ┌──────────────────────────────────────────────┐                           │
  │     │  thread_T2 (Server 工作线程)                  │                           │
  │     │  ┌────────────────────────────────────────┐  │                           │
  │     │  │ wait.thread_todo ──list──▶ [txn] ──┐   │  │                           │
  │     │  └────────────────────────────────────┼───┘  │                           │
  │     └──────────────────────────────────────┼──────┘                           │
  │                                          │                                     │
  │     如果 to_thread == NULL（无空闲线程）:   │                                     │
  │     ┌──────────────────────────────────┐  │                                     │
  │     │  proc_B                          │  │                                     │
  │     │  ┌────────────────────────────┐  │  │                                     │
  │     │  │ todo ──list──▶ [txn] ──────┼──┼─┘                                     │
  │     │  └────────────────────────────┘  │  │                                     │
  │     └──────────────────────────────────┘  │                                     │
  │                                           │                                     │
  │  3) 唤醒等待中的线程                        │                                     │
  │     ┌──────────────────────────────────┐  │                                     │
  │     │  wake_up_interruptible(           │  │                                     │
  │     │    &thread_T2->wait               │  │                                     │
  │     │  )                                │  │                                     │
  │     └──────────────────────────────────┘  │                                     │
  │                                           │                                     │
  │  4) Client 线程 T1 进入睡眠等待回复         │                                     │
  │     ┌──────────────────────────────────┐  │                                     │
  │     │  thread_T1 加入                   │  │                                     │
  │     │  proc_B->wait 等待队列             │  │                                     │
  │     │  (等待 Server 回复)                │  │                                     │
  │     └──────────────────────────────────┘  │                                     │
  │                                           │                                     │
  └────────────────────────────────────────────────────────────────────────────────┘
```

### 阶段 5：Server 接收并处理

```
═══════════════════════════════════════════════════════════════════════════════════
  阶段 5: Server 内核态 → 用户态（接收请求）
═══════════════════════════════════════════════════════════════════════════════════

  ┌─ Server 线程被唤醒 ────────────────────────────────────────────────────────────┐
  │                                                                                │
  │  thread_T2 从 wait 上醒来                                                      │
  │       │                                                                        │
  │       ▼                                                                        │
  │  binder_thread_read()                                                          │
  │       │                                                                        │
  │       ├─▶ 从 thread_T2->wait.thread_todo 或 proc_B->todo 取出 binder_transaction│
  │       │                                                                        │
  │       ├─▶ 构建返回给用户的 binder_transaction_data:                              │
  │       │   ┌──────────────────────────────────────────────┐                     │
  │       │   │  BR_TRANSACTION {                            │                     │
  │       │   │    target.ptr = node->ptr     (0xBB)         │                     │
  │       │   │    target.cookie = node->cookie (0xAA)       │                     │
  │       │   │    code = 1                                  │                     │
  │       │   │    data_size = N                             │                     │
  │       │   │    data.buffer = buffer 在 proc_B 用户空间的  │                     │
  │       │   │                    虚拟地址偏移                │                     │
  │       │   │  }                                           │                     │
  │       │   └──────────────────────────────────────────────┘                     │
  │       │                                                                        │
  │       └─▶ 将事务挂到 thread_T2->transaction_todo                               │
  │                                                                                │
  └────────────────────────────────────────────────────────────────────────────────┘

  ┌─ Server 用户态直接读取数据（零拷贝！）────────────────────────────────────────────┐
  │                                                                                │
  │  proc_B 用户空间虚拟地址                                                         │
  │  ┌──────────────────────────────────────────────────────────┐                  │
  │  │  mmap 映射区域                                           │                  │
  │  │  ┌──────────────────────────────────────────────────┐   │                  │
  │  │  │  binder_buffer 的 data 区域                       │   │                  │
  │  │  │  ┌────────────────────────────────────────────┐   │   │                  │
  │  │  │  │  arg1 = 42                                 │   │   │                  │
  │  │  │  │  arg2 = "hello"                            │   │   │                  │
  │  │  │  │  obj (已 fixup 为 handle 形式)              │   │   │                  │
  │  │  │  └────────────────────────────────────────────┘   │   │                  │
  │  │  └──────────────────────────────────────────────────┘   │                  │
  │  │  ▲                                                       │                  │
  │  │  │  Server 用户态直接通过指针读取，无需任何拷贝！            │                  │
  │  └──────────────────────────────────────────────────────────┘                  │
  │                                                                                │
  │  Server 用户态处理逻辑:                                                         │
  │  1. 解析 Parcel 数据                                                           │
  │  2. 根据 target.cookie 找到对应的 Binder 对象                                   │
  │  3. 调用 onTransact(code, data, reply)                                         │
  │  4. 将结果写入 reply Parcel                                                     │
  │                                                                                │
  └────────────────────────────────────────────────────────────────────────────────┘
```

### 阶段 6：Server 回复 → Client 接收

```
═══════════════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════════════

  ┌─ Server 发送回复 ──────────────────────────────────────────────────────────────┐
  │                                                                                │
  │  Server 用户态                                                                 │
  │  ┌──────────────────────────────────────┐                                      │
  │  │  ioctl(BINDER_WRITE, reply_data)     │                                      │
  │  │  tr.target.handle = 0 (reply)        │                                      │
  │  │  tr.data = reply Parcel              │                                      │

  │                     │                                                          │
  └─────────────────────┼──────────────────────────────────────────────────────────┘

  ┌─ 内核处理回复 ─────────────────────────────────────────────────────────────────┐
  │                                                                                │
  │  binder_transaction(reply=true)                                                │
  │       │                                                                        │
  │       ├─▶ 从 thread_T2->transaction_todo 获取原始事务                           │
  │       │   original_txn = thread_T2->transaction_todo                           │
  │       │                                                                        │
  │       ├─▶ 通过原始事务找到回复目标:                                              │
  │       │   target_thread = original_txn->from_thread ──▶ thread_T1 (Client)     │
  │       │   target_proc   = original_txn->from_proc   ──▶ proc_A  (Client)       │
  │       │                                                                        │
  │       ├─▶ 在 proc_A 中分配新的 binder_buffer                                   │
  │       │   reply_buffer = binder_alloc_buf(proc_A, reply_size, ...)             │
  │       │                                                                        │
  │       ├─▶ 拷贝回复数据到 proc_A 的缓冲区 (一次拷贝)                              │
  │       │   copy_from_user(reply_buffer, server_user_data, reply_size)           │
  │       │                                                                        │
  │       ├─▶ 构建回复事务 reply_txn:                                               │
  │       │   ┌──────────────────────────────────────────────┐                     │
  │       │   │  binder_transaction (reply)                  │                     │
  │       │   │  from_proc  → proc_B                         │                     │
  │       │   │  from_thread→ thread_T2                      │                     │
  │       │   │  to_proc    → proc_A  ◄── 回到 Client!       │                     │
  │       │   │  to_thread  → thread_T1                      │                     │
  │       │   │  buffer     → reply_buffer (in proc_A)       │                     │
  │       │   └──────────────────────────────────────────────┘                     │
  │       │                                                                        │
  │       ├─▶ 将 reply_txn 加入 proc_A->todo 或 thread_T1->wait.thread_todo        │
  │       │                                                                        │
  │       └─▶ wake_up_interruptible(&thread_T1->wait)                              │
  │           (唤醒正在睡眠等待的 Client 线程!)                                       │
  │                                                                                │
  └────────────────────────────────────────────────────────────────────────────────┘

  ┌─ Client 接收回复 ──────────────────────────────────────────────────────────────┐
  │                                                                                │
  │  thread_T1 被唤醒                                                              │
  │       │                                                                        │
  │       ├─▶ 从 wait 队列取出 reply_txn                                           │
  │       │                                                                        │
  │       ├─▶ 构建返回给用户的数据:                                                  │
  │       │   ┌──────────────────────────────────────────────┐                     │
  │       │   │  BR_REPLY {                                  │                     │
  │       │   │    data_size = reply_size                    │                     │
  │       │   │    data.buffer = reply_buffer 在 proc_A      │                     │
  │       │   │                  用户空间的虚拟地址             │                     │
  │       │   │  }                                           │                     │
  │       │   └──────────────────────────────────────────────┘                     │
  │       │                                                                        │
  │       ├─▶ 清理事务链:                                                           │
  │       │   thread_T1->transaction_stack = original_txn->next                    │
  │       │   释放 original_txn 和 reply_txn                                       │
  │       │                                                                        │
  │       └─▶ 返回用户态                                                            │
  │                                                                                │
  │  Client 用户态                                                                  │
  │  ┌──────────────────────────────────────┐                                      │
  │  │  ioctl 返回!                         │                                      │
  │  │  读取 reply_buffer 中的数据            │                                      │
  │  │  (直接通过 mmap 映射读取，零拷贝!)      │                                      │
  │  │  解析 Parcel，获得调用结果              │                                      │
  │  └──────────────────────────────────────┘                                      │
  │                                                                                │
  └────────────────────────────────────────────────────────────────────────────────┘
```
