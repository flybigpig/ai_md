### 4. WindowState — 窗口的核心描述

```java
// WindowState 是 WMS 中代表一个窗口的核心类
class WindowState {
    // ─── 身份标识 ───
    Session mSession;              // 窗口所属的 Session (与客户端进程绑定)
    int mAppId;                    // 应用 UID
    String mName;                  // 窗口名称 (用于调试)
    IWindow mClient;               // 客户端的 IWindow Binder 代理

    // ─── 窗口属性 ───
    WindowManager.LayoutParams mAttrs;  // 窗口布局参数
    // mAttrs.type    → 窗口类型 (TYPE_APPLICATION, TYPE_INPUT_METHOD 等)
    // mAttrs.flags   → 窗口标志 (FLAG_NOT_FOCUSABLE 等)
    // mAttrs.gravity → 窗口对齐方式
    // mAttrs.x/y     → 窗口位置
    // mAttrs.width/height → 窗口尺寸

    // ─── 层级与容器 ───
    WindowToken mToken;            // 窗口令牌 (标识窗口归属的 Activity/组件)
    WindowContainer mContainer;    // 父容器 (DisplayContent/Task/TaskStack)
    int mLayer;                    // Z-Order 层级值

    // ─── 显示状态 ───
    boolean mHasSurface;           // 是否已有 Surface
    boolean mIsVisible;            // 是否可见
    boolean mIsAnimating;          // 是否在动画中

    // ─── 焦点与输入 ───
    boolean mHasFocus;             // 是否有输入焦点
    boolean mCanReceiveKeys;       // 是否能接收按键事件

    // ─── 输入法相关 ───
    boolean mIsImWindow;           // 是否是输入法窗口
    boolean mIsWallpaper;          // 是否是壁纸窗口
    boolean mIsFloatingLayer;      // 是否在浮动层

    // ─── 触摸区域 ───
    Rect mFrame;                   // 窗口在屏幕上的实际矩形区域
    Rect mContainingFrame;         // 父容器分配给它的可用区域
    Rect mSystemDecorRect;         // 系统装饰(状态栏/导航栏)占用的区域
}
```

### 5. 添加窗口的完整流程

```
═══════════════════════════════════════════════════════════════════════════════════
  WMS 添加窗口流程 (addWindow)
═══════════════════════════════════════════════════════════════════════════════════

  应用进程                                    WMS (system_server)
  ┌──────────────────┐                        ┌──────────────────────────────────┐
  │                  │                        │                                  │
  │  Activity.onCreate()                      │                                  │
  │       │          │                        │                                  │
  │       ▼          │                        │                                  │
  │  PhoneWindow     │                        │                                  │
  │  .setContentView()                        │                                  │
  │       │          │                        │                                  │
  │       ▼          │                        │                                  │
  │  WindowManager   │                        │                                  │
  │  .addView()      │                        │                                  │
  │       │          │                        │                                  │
  │       ▼          │                        │                                  │
  │  Session.add()   │                        │                                  │
  │       │          │                        │                                  │
  │       │  IPC (Binder)                     │                                  │
  │       │  IWindowManager.addWindow()       │                                  │
  │       ├───────────────────────────────────▶│                                  │
  │       │          │                        │  addWindow() {                   │
  │       │          │                        │    // 1. 权限检查                 │
  │       │          │                        │    checkCallingPermission()       │
  │       │          │                        │                                  │
  │       │          │                        │    // 2. 创建 WindowState         │
  │       │          │                        │    win = new WindowState(...)     │
  │       │          │                        │                                  │
  │       │          │                        │    // 3. 确定窗口层级             │
  │       │          │                        │    assignLayer(win)               │
  │       │          │                        │    // type=1 → layer=1~99        │
  │       │          │                        │    // type=2005 → layer=400 (IME)│
  │       │          │                        │                                  │
  │       │          │                        │    // 4. 加入容器层级树           │
  │       │          │                        │    mRoot.addWindow(win)           │
  │       │          │                        │    // 插入到 DisplayContent 的    │
  │       │          │                        │    // 对应 Task 下                │
  │       │          │                        │                                  │
  │       │          │                        │    // 5. 请求 Surface             │
  │       │          │                        │    win.createSurfaceLocked()      │
  │       │          │                        │    // 向 SurfaceFlinger 申请      │
  │       │          │                        │    // 创建 BufferQueue            │
  │       │          │                        │                                  │
  │       │          │                        │    // 6. 调整焦点                 │
  │       │          │                        │    adjustFocusLocked(win)         │
  │       │          │                        │                                  │
  │       │          │                        │    // 7. 触发布局重算             │
  │       │          │                        │    mRoot.performLayoutAndPlace()  │
  │       │          │                        │  }                               │
  │       │          │                        │                                  │
  │       │◀───────────────────────────────────┤  返回: 窗口已添加               │
  │       │          │                        │                                  │
  └──────────────────┘                        └──────────────────────────────────┘
```

```
  │  │ STATE_ALWAYS_HIDDEN  │ 无论什么情况都隐藏输入法                        │    │
```

## 五、WMS 与 IMS 的完整协作时序

```
═══════════════════════════════════════════════════════════════════════════════════
  完整时序: 用户点击 EditText → 输入法弹出 → 输入文字 → 点击完成 → 输入法收起
═══════════════════════════════════════════════════════════════════════════════════

  时间轴 ──────────────────────────────────────────────────────────────────────▶

  T1: 用户点击 EditText
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  InputDispatcher → WMS → Activity                                      │
  │  Activity.onTouchEvent() → EditText.requestFocus()                      │
  │  WMS 检测到焦点变化 → 通知 IMS                                          │
  │  IMS 检查 softInputMode → 决定显示输入法                                 │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T2: IMS 绑定输入法
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  IMS.bindToMethod() → 输入法进程                                        │
  │  输入法 InputMethodService.onCreateInputMethodSessionInterface()         │
  │  IMS.startInputInnerLocked() → 通知输入法开始接收输入                     │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T3: 输入法窗口添加
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  输入法进程 WindowManager.addView(keyboardView, type=TYPE_INPUT_METHOD) │
  │  → WMS.addWindow() 创建 WindowState (layer=400)                        │
  │  → 加入 mImeContainer                                                  │
  │  → WMS.mInputMethodWindow = imeWin                                     │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T4: 窗口重新布局
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  WMS.performLayoutAndPlaceSurfacesLocked()                              │
  │  → 计算 IME 窗口位置 (屏幕底部)                                         │
  │  → 根据 softInputMode 调整应用窗口:                                      │
  │    ADJUST_RESIZE: 压缩应用窗口高度                                       │
  │    ADJUST_PAN: 平移应用窗口                                              │
  │  → 通知应用: IWindow.resized() → onSizeChanged()                        │
  │  → SurfaceFlinger 重新合成画面                                          │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T5: 用户输入文字
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  触摸键盘按键 → 输入法进程处理                                            │
  │  输入法 → InputConnection.commitText("你") → EditText                   │
  │  EditText 更新显示                                                       │
  │  (数据流: 输入法进程 → Binder → 应用进程, 不经过 WMS/IMS)                │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T6: 用户点击 "完成" 或其他区域
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  场景 A: 点击 "完成" 按钮                                                │
  │  → EditorInfo.imeOptions = IME_ACTION_DONE                              │
  │  → EditText 调用 InputMethodManager.hideSoftInputFromWindow()           │
  │  → IMS 通知输入法 hideWindow()                                          │
  │  → 输入法窗口移除 → WMS 重新布局 → 应用窗口恢复全高                       │
  │                                                                         │
  │  场景 B: 点击 Activity 空白区域                                          │
  │  → 触摸事件分发给 Activity (不在 IME 窗口范围内)                          │
  │  → EditText.clearFocus()                                                │
  │  → WMS 检测到焦点变化 → 通知 IMS                                         │
  │  → IMS 隐藏输入法 (同场景 A)                                             │
  └─────────────────────────────────────────────────────────────────────────┘
       │
       ▼
  T7: 输入法窗口移除
  ┌─────────────────────────────────────────────────────────────────────────┐
  │  WMS.removeWindowLocked(imeWin)                                         │
  │  → 从 mImeContainer 中移除                                              │
  │  → mInputMethodWindow = null                                            │
  │  → 重新布局: 应用窗口恢复原始高度                                         │
  │  → SurfaceFlinger 重新合成                                              │
  └─────────────────────────────────────────────────────────────────────────┘
```

## 七、总结

| 维度 | WMS | IMS |
|------|-----|-----|
| **核心职责** | 窗口生命周期、Z-Order、布局、Surface | 输入法绑定/切换、输入焦点跟踪 |
| **管理对象** | WindowState (所有类型的窗口) | InputMethodInfo (输入法元数据) |
| **关键容器** | RootWindowContainer → DisplayContent → Task → AppWindowToken | mMethodMap (输入法列表) |
| **与输入法关系** | 实际创建/管理输入法窗口 (WindowState) | 决定何时显示/隐藏/切换输入法 |
| **布局影响** | 根据 IME 可见性调整应用窗口大小 | 通知 WMS 输入法窗口高度变化 |
| **事件处理** | 分发触摸事件到正确的窗口 | 接收按键事件并转发给输入法 |

**协作核心原则：**
- **IMS 是决策者**：决定输入法应该显示/隐藏/切换
- **WMS 是执行者**：实际管理输入法窗口、调整布局、分发事件
- **输入法窗口是 TYPE_INPUT_METHOD**：层级 400，位于应用窗口之上、系统对话框之下
- **焦点变化是触发器**：几乎所有 WMS-IMS 协作都由焦点变化驱动
