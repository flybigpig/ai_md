  - 默认注册 41 个 CoreStartable（含 NotificationChannels 为 @PerUser）；注意 CentralSurfacesImpl/QSFragment/NavigationBarController 不在列表（它们是 UI 组件，间接启动）
  - 耗时告警：单个 start() > 1000ms 打印 Log.w；启动顺序确定性（TreeMap）；厂商组件永远最后
  - 新增组件两步：实现类 + Module 一行 @ClassKey；车载每用户组件加 @PerUser；厂商隔离用 config_systemUIVendorComponent overlay（反射加载）
