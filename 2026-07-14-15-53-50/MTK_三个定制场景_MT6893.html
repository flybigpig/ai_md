场景一：改 ProjectConfig 开关

ProjectConfig.mk 是 MTK 所有 MTK_* 宏的"总开关"，改完会同时影响 Make 变量和 C/C++ 编译宏。

位置（优先级从高到低）：

device/mediatek/mt6893/ProjectConfig.mk        # ★ 你主要改这里
device/mediatek/common/ProjectConfig.mk        # 公共默认值
vendor/mediatek/proprietary/build/...           # 部分宏来源

改法示例（开一个功能宏）：

# device/mediatek/mt6893/ProjectConfig.mk
MTK_CAMERA_APP = yes
MTK_GMO_RAM_OPTIMIZE = no
MTK_MIRAVISION_SUPPORT = yes
MY_CUSTOM_FEATURE = yes        # 自定义宏也能加

宏怎么传播：

  • Make 层：所有 Android.mk / Android.bp 可直接用 $(MTK_CAMERA_APP) 做条件编译。
  • C/C++ 层：MTK 在编译期生成配置头，典型在 
    out/target/product/mt6893/obj/CONFIG/autoconfig.mk     # Make 变量全集
out/target/product/mt6893/obj/CONFIG/ProjectConfig.h    # 部分 BSP 生成给 C 用
    代码里用 #ifdef MTK_MIRAVISION_SUPPORT 判断。具体生成头路径以你 BSP 的 device/mediatek/build/ 下 gen 脚本为准（不同版本可能在 out/.../include/）。

生效：

source build/envsetup.sh && lunch mt6893-userdebug
mmm device/mediatek/mt6893/        # 或全编
坑：只改 out/ 下的生成文件没用，下次编译会被覆盖；必须改 device/mediatek/mt6893/ProjectConfig.mk 源文件。

场景二：加一个 LCM（LCD）

LCM 驱动要同时加 LK（开机 logo 阶段）和 kernel 两份，且 DTS 里配 GPIO。面板初始化序列（DSI cmd）由屏厂提供。

2.1 LK 侧（开机即显示）

graph LR A["新建 LK LCM 驱动文件夹"] --> B["注册到 lcm_list.c"] B --> C["编译 lk.bin"] C --> D["烧录 lk"]
  • 新建驱动目录： 
    vendor/mediatek/proprietary/bootable/bootloader/lk/dev/lcm/<vendor>_<model>_lcm/
├── lcm.c            # 实现 LCM_DRIVER
├── lcm_drv.h
└── lcm_params.h
  • lcm.c 核心结构体： 
    C
LCM_DRIVER xxx_lcm_drv = {
    .name           = "XXX_1080P_LCM",
    .set_util_funcs = lcm_set_util_funcs,
    .get_params     = lcm_get_params,   // 填分辨率/时序/接口(DSI/RGB)
    .init           = lcm_init,         // 屏厂给的 DSI 初始化序列
    .suspend        = lcm_suspend,
    .resume         = lcm_resume,
    .set_backlight  = lcm_set_backlight,
};
  • 注册到列表（vendor/.../lk/dev/lcm/lcm_list.c）： 
    C
extern LCM_DRIVER xxx_lcm_drv;
LCM_DRIVER *lcm_driver_list[] = {
    &xxx_lcm_drv,
    // ...原有 LCM
    NULL,
};

2.2 Kernel 侧

kernel-5.15/drivers/misc/mediatek/lcm/<vendor>_<model>/
├── <vendor>_<model>_lcm.c
└── Makefile   # obj-y += <vendor>_<model>_lcm.o

同样实现 LCM_DRIVER 并加入 lcm_list.c（kernel 版）。

2.3 DTS（GPIO / 电源）

// kernel-5.15/arch/arm64/boot/dts/mediatek/mt6893-<board>.dts
&lcm {
    lcm_name = "XXX_1080P_LCM";
    lcm_width = <1080>;
    lcm_height = <2400>;
    reset-gpios = <&pio 45 0>;     // 屏 reset 脚
    power-gpios = <&pio 46 0>;
};

2.4 编译烧录

./mk mt6893 r lk          # 只重编 LK
mmm kernel-5.15/drivers/misc/mediatek/lcm/   # 或整编
# 烧录 lk.bin + boot/vendor_boot + dtbo
屏不亮先查：LK 和 kernel 的 LCM 名字必须一致；reset/power GPIO 与硬件原理图对得上；DSI 初始化序列是否完整。

场景三：调 camera 参数

MTK camera 调参分两层：sensor 驱动（分辨率/上电/I2C） 和 tuning（3A：AE/AWB/AF 表）。

3.1 Sensor 驱动与列表

vendor/mediatek/proprietary/custom/mt6893/hal/imgsensor/
├── <sensor>/
│   ├── <sensor>_sensor.c          # 上电/I2C/分辨率表
│   ├── <sensor>_sensor.h
│   └── <sensor>_sensor_setting.c  # preview/capture 寄存器序列
└── imgsensor_sensor_list.cpp      # ★ 把 sensor 注册进列表

注册（sensorlist.cpp）：

C
MSDK_SENSOR_INIT_FUNCTION_STRUCT sensorList[] = {
    {XXX_SENSOR_ID, SENSOR_DRVNAME_XXX, xxx_SensorInit},
    // ...
};

3.2 Tuning（3A 参数）

vendor/mediatek/proprietary/custom/mt6893/hal/imgsensor/<sensor>/
├── <sensor>_tuning_ae.h     # 曝光/增益表、AE target
├── <sensor>_tuning_awb.h    # 白平衡色温点
└── <sensor>_tuning_af.h     # 对焦范围

常见"调参"改这里，例如调亮度（改 AE target / 曝光档位）：

C
// <sensor>_tuning_ae.h (示意)
static AE_SCENE_T g_AE_Scene[AE_SCENE_NUM] = {
    {AE_SCENE_AUTO,  /* target */ 0x40, /* min */ 0, /* max */ 0xFF},
};

3.3 Kernel sensor 驱动 + DTS

kernel-5.15/drivers/misc/mediatek/imgsensor/<sensor>/
└── <sensor>_driver.c        # kd_imgsensor 注册、I2C、MCLK、reset
// kernel-5.15/arch/arm64/boot/dts/mediatek/mt6893-<board>.dts
&kd_camera_hw1 {
    cam0_vcm_power_gpio = <&pio 50 0>;
    cam0_rst_gpio       = <&pio 51 0>;
    cam0_pnd_gpio       = <&pio 52 0>;
    cam0_mclk_gpio      = <&pio 53 0>;
    port {
        camera0: endpoint { remote-endpoint = <&imgsensor0>; };
    };
};

3.4 编译烧录

mmm vendor/mediatek/proprietary/custom/mt6893/hal/imgsensor/
mmm vendor/mediatek/proprietary/hardware/mtkcam/   # camera HAL
# 重编 boot/vendor_boot + 烧录；HAL 改了还要重编 vendor
调参排障：黑屏先查 imgsensor 能否 probe 到 sensor ID（kernel log 搜 imgsensor）；偏色查 AWB 表；过曝/欠曝查 AE target。

三个场景的共性提醒

  • kernel/DTS 改动在 Android 14 走 vendor_boot.img + dtbo.img，别只烧 boot。
