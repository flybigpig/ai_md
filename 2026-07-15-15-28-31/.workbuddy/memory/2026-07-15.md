# 2026-07-15 工作日志

## 新项目:android-agent-harness(Kotlin/JVM)
- 目录:`android-agent-harness/`
- 目标形态:主机侧 Kotlin/JVM harness,经 ADB 驱动 Android 设备,做「截图 + UI 树 → LLM 决策 → 动作」感知-行动回环(computer-use 风格)。
- 环境:JDK 21;adb 在 `C:\D\SDK\platform-tools\adb.exe`;无 gradle CLI,改用 Gradle Wrapper 8.10.2(手动下载 wrapper jar/脚本)。
- 技术选型:Kotlin 2.0.21 + kotlinx-serialization-json 1.7.3 + coroutines 1.9.0;HTTP 用 JDK 内置 `java.net.http`(不引 ktor)。
- 架构分层:
  - `adb.AdbClient` 封装 adb 进程调用
  - `device.Device` 感知(screencap / uiautomator dump / wm size / dumpsys)+ 动作(tap/swipe/input/key/openApp);`UiNode` + `UiHierarchyParser`(DOM 解析,禁 DTD 防 XXE)
  - `tools.Tool/ToolRegistry/DeviceTools/Schema/UiContext`,工具:get_ui/screenshot/tap_index/tap_xy/swipe/input_text/press_key/open_app/finish
  - `llm.LlmClient` 抽象 + `MockLlmClient`(脚本回放/启发式)+ `OpenAiLlmClient`(OpenAI 兼容 function calling,可指向本地 8081)
  - `agent.AgentLoop` 主回环 + `Prompts` 系统提示词
  - `Main.kt` CLI:--goal/--mock/--adb/--serial/--base-url/--api-key/--model/--max-steps/--out
- 测试:`AgentLoopTest` 用内存工具验证回环(不依赖真机)。
- 设计约定:先建 Mock 回环跑绿,再挂真实 LLM;tap 优先用 get_ui 的 index 引用元素。
