## android-inapp-agent（设备内 App agent）从零搭建

用户把 harness 方向从「主机侧 ADB」掉头为「设备内 App agent」。新建独立 Android 应用工程
`android-inapp-agent/`（与 `android-agent-harness/` 并存）。

核心选型：
- 形态：在设备内跑的 Android App（Kotlin/JVM + AGP 8.5.2 + Kotlin 1.9.24，compileSdk/targetSdk 34，minSdk 24）。
- 感知/动作核心：`AgentAccessibilityService`（getRootInActiveWindow 树 → Perception 确定性索引扁平节点；
  dispatchGesture 点击/滑动；performGlobalAction 系统键；节点 ACTION_SET_TEXT 填字；openApp；MediaProjection 截图）。
- LLM：`LlmClient` 抽象 + `OpenAiLlmClient`（function calling，带文本 JSON 兜底）+ `MockLlmClient`（启发式 grounding，免模型验证回环）。
- 回环：`AgentLoop`（感知-决策-行动，兼容 tool_calling 与本地模型文本 JSON 动作）+ `AgentService`（前台服务 specialUse）+ `MainActivity`（控制/日志/授权）。
- 9 个工具：get_ui / tap_index / tap_xy / swipe / input_text / press_key / open_app / screenshot / finish。

进度：源码已全部写完，正在 `./gradlew assembleDebug` 编译验证（首次需下载 Gradle 8.10.2 + AGP + 依赖）。
环境已确认：SDK 有 android-34 + build-tools 34.0.0 + 许可证，JDK21，真机 01602329009316 在线。
注意点：Kotlin 序列化插件已加 `org.jetbrains.kotlin.plugin.serialization`；主题用 Material3 DayNight 以兼容 Material 控件。
