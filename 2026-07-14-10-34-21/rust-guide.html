1. Rust 是什么 为什么值得学

Rust 是一门系统级编程语言，主打内存安全与高性能，且不依赖垃圾回收（GC）。它的核心卖点：

  • 内存安全靠编译期检查：通过「所有权（ownership）」系统在编译时就杜绝空指针、悬垂引用、数据竞争。
  • 零成本抽象：高级写法（如迭代器、泛型）编译后几乎没有运行时开销。
  • 无畏并发：编译器保证多线程共享数据时的安全性。
  • 丰富工具链：cargo 统一管理构建、依赖、测试、文档。
Rust 的难点集中在所有权。把它当成「编译器帮你管内存的规则」，而不是负担，会轻松很多。建议前几章反复体会第 7、8 节。

2. 安装与环境

Rust 官方提供 rustup 工具链管理器，一条命令装好编译器 rustc 和包管理器 cargo。

# 安装工具链（Windows / macOS / Linux 通用）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version      # 查看编译器版本
cargo --version      # 查看包管理器版本

# 更新工具链
rustup update
Windows 用户也可直接下载 官方安装器。安装完成后建议重启终端，让环境变量生效。

日常开发用得最多的三个命令：

命令作用
cargo new 项目名创建新项目（含 Cargo.toml）
cargo build编译项目
cargo run编译并直接运行

3. Hello World

cargo new hello_rust
cd hello_rust
cargo run

生成的 src/main.rs 内容如下，fn main() 是程序入口：

fn main() {
    println!("Hello, world!");
}
println! 末尾的 ! 表示它是宏（macro），不是普通函数。Rust 中宏用 ! 区分。

4. 变量与可变性

Rust 默认变量不可变（immutable），要修改必须显式加 mut。这是「防 bug 优先」的设计。

fn main() {
    let x = 5;          // 不可变绑定
    let mut y = 10;     // 可变绑定
    y = 20;
    println!("x = {}, y = {}", x, y);

    let x = x + 1;      // 阴影（shadowing）：重新定义同名变量
    println!("x after shadowing = {}", x);
}
若对不可变变量重新赋值（如 x = 6;），编译器会直接报错。这能在编译期拦住大量意外修改。
Shadowing（阴影）与 mut 不同：它不是修改原值，而是创建一个同名新变量，可借此改变类型（例如把 String 阴影成 usize）。

5. 数据类型

5.1 标量类型

fn main() {
    let a: i32 = -42;       // 有符号 32 位整数
    let b: u8 = 255;        // 无符号 8 位整数（0~255）
    let c: f64 = 3.14;      // 64 位浮点（默认浮点类型）
    let d: bool = true;     // 布尔
    let e: char = 'R';      // 字符（Unicode，占 4 字节）
    println!("{} {} {} {} {}", a, b, c, d, e);
}
整数后缀可写 i8/i16/i32/i64/i128/isize 与 u8/u16/...。默认整数类型是 i32，默认浮点是 f64。

5.2 元组（Tuple）

fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
    let (x, y, z) = tup;          // 解构（destructuring）
    println!("y = {}", y);
    println!("first = {}", tup.0); // 用下标访问
}

5.3 数组（Array）

fn main() {
    let arr = [1, 2, 3, 4, 5];
    let first = arr[0];
    println!("first = {}", first);
}
数组长度固定且在栈上。若需要动态增长，用第 12 节的 Vec。越界访问会在运行时 panic（编译期不一定能发现）。

6. 函数与控制流

6.1 函数与返回值

fn add(a: i32, b: i32) -> i32 {
    a + b   // 末尾无分号 = 表达式，作为返回值
}

fn main() {
    let result = add(3, 4);
    println!("3 + 4 = {}", result);
}
Rust 中语句（statement）无返回值，表达式（expression）有值。函数体最后一个表达式（不带分号）就是返回值；也可写 return a + b;。

6.2 控制流

fn main() {
    let number = 7;

    if number < 5 {
        println!("小于 5");
    } else if number == 5 {
        println!("等于 5");
    } else {
        println!("大于 5");
    }

    // if 是表达式，可直接赋值
    let big = if number > 10 { 100 } else { 0 };
    println!("big = {}", big);

    let mut count = 0;
    while count < 3 {
        println!("while: {}", count);
        count += 1;
    }

    for i in 0..3 {
        println!("for: {}", i);
    }

    let mut n = 0;
    loop {
        n += 1;
        if n == 3 { break; }
    }
    println!("loop ended at {}", n);
}
if 作为表达式时，各分支必须返回相同类型。范围 0..3 表示 0、1、2（不含 3）。

7. 所有权（Ownership） 核心

每个值都有唯一「所有者」。当所有者离开作用域，值被自动释放（drop）。把值传给函数时，默认发生移动（move）——所有权转交，原变量失效。

fn main() {
    let s = String::from("hello");  // s 拥有堆上的字符串
    takes_ownership(s);              // 所有权被移动（move）
    // println!("{}", s);           // 编译错误：s 已失效

    let x = 5;
    makes_copy(x);                   // i32 实现了 Copy，仍可继续使用
    println!("x = {}", x);
}

fn takes_ownership(text: String) {
    println!("got: {}", text);
}  // text 离开作用域，内存被释放（drop）

fn makes_copy(num: i32) {
    println!("num = {}", num);
}
为什么要在意？像 i32、bool、f64、固定长度数组这些实现了 Copy trait 的类型，赋值时是「按位复制」，旧变量仍有效；而 String、Vec 等在堆上分配，赋值时发生 move。这正是 Rust 不靠 GC 也能保证内存安全的关键。

8. 引用与借用（References & Borrowing）

用 & 借取值而不夺走所有权，函数结束后原变量依然可用。

fn main() {
    let s = String::from("hello");
    let len = calculate_length(&s);   // 借用，不转移所有权
    println!("'{}' 的长度是 {}", s, len);  // s 仍可用
}

fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 是引用，不会释放原字符串

8.1 可变引用

fn main() {
    let mut s = String::from("hello");
    change(&mut s);
    println!("{}", s);
}

fn change(s: &mut String) {
    s.push_str(", world");
}
借用规则（编译期强制）：同一时刻，要么有多个不可变引用 &T，要么有唯一一个可变引用 &mut T，二者不可共存。这条规则杜绝了数据竞争。

9. 切片（Slice）

切片让你不拷贝地引用集合的一部分，类型为 &[T]（数组切片）或 &str（字符串切片）。

fn main() {
    let s = String::from("hello world");
    let hello = &s[0..5];     // "hello"
    let world = &s[6..11];    // "world"
    println!("{} - {}", hello, world);
}
字符串字面量 let s = "hello"; 里的 s 本身就是 &str——一个指向二进制只读区的切片。

10. 结构体与方法

struct User {
    username: String,
    email: String,
    active: bool,
    sign_in_count: u64,
}

fn main() {
    let mut user1 = User {
        username: String::from("alice"),
        email: String::from("alice@example.com"),
        active: true,
        sign_in_count: 1,
    };
    user1.sign_in_count += 1;
    println!("{} 登录了 {} 次", user1.username, user1.sign_in_count);
}

10.1 用 impl 定义方法

struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("面积 = {}", rect.area());
}
&self 是 self: &Self 的简写，表示借用实例。需要修改自身时用 &mut self，要拿走所有权时用 self。

11. 枚举与 match

枚举可携带不同类型的数据，配合 match 做 exhaustive（穷尽）模式匹配。

enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}

fn main() {
    let home = IpAddr::V4(127, 0, 0, 1);
    let loopback = IpAddr::V6(String::from("::1"));

    describe(&home);
    describe(&loopback);
}

fn describe(ip: &IpAddr) {
    match ip {
        IpAddr::V4(a, b, c, d) => println!("IPv4: {}.{}.{}.{}", a, b, c, d),
        IpAddr::V6(addr) => println!("IPv6: {}", addr),
    }
}

11.1 Option 枚举：没有 null

Rust 没有 null，用标准库 Option<T> 表示「可能有值 / 可能没有」。这强迫你处理「空」的情况。

fn main() {
    let some_number = Some(5);
    let no_number: Option<i32> = None;

    let doubled = match some_number {
        Some(x) => Some(x * 2),
        None => None,
    };
    println!("{:?}", doubled);
}
Option<T> 与 T 是不同类型，不能直接当 T 用，必须 match 或 unwrap 取出，从类型层面消灭「空指针」。

12. 集合：Vec 与 HashMap

12.1 动态数组 Vec

fn main() {
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    v.push(2);
    v.push(3);

    for i in &v {
        println!("{}", i);
    }

    let v2 = vec![10, 20, 30];   // 宏快速构造
    println!("第二个元素: {}", v2[1]);
}

12.2 哈希表 HashMap

use std::collections::HashMap;

fn main() {
    let mut scores: HashMap<String, i32> = HashMap::new();
    scores.insert(String::from("Blue"), 10);
    scores.insert(String::from("Red"), 50);

    let team = String::from("Blue");
    let score = scores.get(&team).copied().unwrap_or(0);
    println!("{} 队得分: {}", team, score);
}
get 返回 Option<&V>。copied() 把 &i32 复制成 i32，unwrap_or(0) 在缺失时给默认值 0。

13. 错误处理

Rust 把可恢复错误用 Result<T, E> 表达，不可恢复错误用 panic!。

use std::num::ParseIntError;

fn parse_number(s: &str) -> Result<i32, ParseIntError> {
    let n = s.parse::<i32>()?;   // ? 运算符：出错时提前返回 Err
    Ok(n)
}

fn main() {
    match parse_number("42") {
        Ok(n) => println!("解析成功: {}", n),
        Err(e) => println!("解析失败: {}", e),
    }
}
? 是错误处理神器：若结果是 Err，直接把错误返回给调用者；若是 Ok，则取出里面的值继续。它只能用在返回 Result 的函数里。

14. 泛型与 Trait

泛型让函数/结构体适用于多种类型；trait 定义「能力/接口」，类似其他语言的接口或抽象类。

fn largest<T: PartialOrd + Copy>(list: &[T]) -> T {
    let mut largest = list[0];
    for &item in list {
        if item > largest {
            largest = item;
        }
    }
    largest
}

trait Summary {
    fn summarize(&self) -> String;
}

struct NewsArticle {
    headline: String,
}

impl Summary for NewsArticle {
    fn summarize(&self) -> String {
        format!("头条新闻：{}", self.headline)
    }
}

fn main() {
    let nums = vec![34, 50, 25, 100, 65];
    println!("最大值: {}", largest(&nums));

    let article = NewsArticle { headline: String::from("Rust 1.0 发布") };
    println!("{}", article.summarize());
}
约束 T: PartialOrd + Copy 表示：类型 T 必须既能比较大小、又能按位复制。这是 Rust「对能力做编译期约束」的典型写法。

15. 实战：猜数字游戏

综合用到：用户输入、随机数、match、loop、错误处理。先新建项目并加依赖：

cargo new guessing_game
cd guessing_game

编辑 Cargo.toml 加入随机数库：

[package]
name = "guessing_game"
version = "0.1.0"
edition = "2021"

[dependencies]
rand = "0.8"

再把下面代码写入 src/main.rs：

use std::io;
use std::cmp::Ordering;
use rand::Rng;

fn main() {
    println!("猜数字游戏！");
    let secret = rand::thread_rng().gen_range(1..=100);

    loop {
        println!("请输入你的猜测：");
        let mut guess = String::new();
        io::stdin().read_line(&mut guess).expect("读取失败");

        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => {
                println!("请输入数字！");
                continue;
            }
        };

        match guess.cmp(&secret) {
            Ordering::Less => println!("太小了！"),
            Ordering::Greater => println!("太大了！"),
            Ordering::Equal => {
                println!("猜对了！");
                break;
            }
        }
    }
}
运行 cargo run 即可游玩。cargo 会自动从 crates.io 下载并编译 rand 依赖。

16. 下一步建议

  • 官方必读：《The Rust Programming Language》（中文版），权威且免费。
  • 动手练：rustlings，一小撮渐进式练习，编译器当老师。
  • 生命周期（lifetime）：本指南未展开，是借用的进阶话题，建议学完所有权后专攻。
  • 刷题巩固：用 LeetCode 简单题练手，重点体会所有权与集合 API。
  • 写小工具：比如文件重命名器、命令行待办，最能建立成就感。
记住 Rust 的学习曲线：前两周在和编译器「吵架」，熬过去之后写出的代码几乎不会在运行时崩——这笔买卖很划算。
