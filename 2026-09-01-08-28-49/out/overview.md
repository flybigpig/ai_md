## 方案设定

一对 40 岁双职工夫妻（育有 12 岁子女），计划 60 岁退休，规划期至 85 岁。

| 项目 | 数值 |
|---|---|
| 家庭年税后收入 | ¥66.0 万 |
| 家庭年支出 | ¥42.0 万（日常 24.6 / 房贷 11.4 / 教育 6.0） |
| 家庭年结余 | ¥24.0 万（养老专项 ¥10 万起，50 岁后 ¥21.4 万） |
| 当前可投资金融资产 | ¥120 万 + 企业年金 ¥28 万 |
| 自住房市值 / 房贷余额 | ¥480 万 / ¥90 万（均不计入养老资产） |
| 退休后年支出 | ¥36 万（今日购买力）→ 60 岁当年名义 ¥59 万 |

## 测算结果

统一折算至 60 岁退休时点现值：

- **总需求 ¥1,462 万** = 退休生活支出需求 ¥1,362 万（26 年，通胀 2.5%，实际贴现率约 0.98%）+ 医疗与长期护理储备 ¥100 万
- **三支柱覆盖 ¥1,268 万** = 第一支柱 ¥327 万（25.8%）+ 第二支柱 ¥143 万（11.3%）+ 第三支柱 ¥798 万（62.9%）
- **缺口 ¥194 万**，覆盖率 **86.7%**
- 60 岁养老资产池 **¥940.9 万**，按 3.5% 年化提取，**84 岁归零**，较 85 岁目标提前 1 年

## 四条行动建议（合计补足 ¥201 万）

1. 提高养老专项储蓄：每月多存 ¥2,000 → **¥49 万**
2. 优化资产配置争取 +0.5% 年化（40–50 岁权益 55%、50–60 岁 35%）→ **¥50 万**
3. 60–64 岁弹性退休 / 半退休收入 ¥8 万/年 → **¥37 万**
4. 企业年金加缴至 ¥4.0 万/年 + 个人养老金顶格税优再投资 → **¥65 万**

补齐 ¥194 万缺口后余约 ¥7 万安全垫，调整后覆盖率约 100.5%。

## 关键假设

通胀 2.5%；积累期年化 6.0%（40–50 岁）/ 4.5%（50–60 岁）；退休后 3.5%；基本养老金首年 ¥15 万、年调 2.0%；规划终止 85 岁；自住房与房贷不计入养老资产。
