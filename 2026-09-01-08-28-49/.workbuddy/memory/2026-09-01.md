# 2026-09-01

## 家庭养老退休规划方案页（单文件 HTML）

- 产出：`out/retirement-plan.html`（单文件、零外部依赖）+ `out/overview.md`
- 场景：40 岁双职工夫妻、60 岁退休、规划至 85 岁；测算结果——需求 ¥1,462 万 / 三支柱覆盖 ¥1,268 万 / 缺口 ¥194 万 / 覆盖率 86.7% / 资产池 84 岁归零；四条建议合计补足 ¥201 万。
- 技术选择：图表不用 Chart.js 等 CDN 库，改为**原生 SVG + 内联 JS 生成**，保证离线可打开。共 4 张图（缺口对比堆叠条、三层堆叠面积曲线、三支柱环形、现金流组合双轴图）+ 26 行明细表。
- 视觉风格：暖白 #FAF6F0 底 + 赤陶棕 #A8622C 主色 + 金/绿/红语义色，卡片圆角 18px、暖调柔和阴影，数字全站 tabular-nums。
- 踩坑记录：
  1. Write 工具单条 JSON 超约 45KB 会被截断 → 拆成 p1~p4 片段分别写，再用 Python（显式 utf-8）合并。
  2. 手写 SVG 堆叠面积图时，闭合路径必须在顶部折线后补两个底角顶点 `L(x_end, y0) L(x_start, y0)`，否则右下角缺块。
  3. 校验方法很有效：Python 正则抽出 `<script>` 内容 → `node --check` 查语法 → Node 里 stub `document.getElementById` 后 eval，检查输出是否含 `NaN`/`undefined`。
- 建模口径备忘：需求与供给均折算至 60 岁现值；退休期折现同步扣 2.5% 通胀（等价实际贴现率约 0.98%）；退休后现金流表"投资收益 = 年初余额 × 3.5%"，年末余额 = 年初 + 收益 − 提取。
