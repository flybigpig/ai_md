# 2026-07-27 工作日志

## 用户查询 Android 17 特性(深度梳理)
- Android 17 = API 级别 37,发布节奏大改:**传统 Developer Preview 被 Android Canary 持续渠道取代**(always-on,功能过内测即进 Canary,支持 OTA,易接 CI)。
- 平台稳定性里程碑目标 3 月;Q2 引入重大行为变更;Q4 次要 SDK 版本。AOSP 源码已开放(分支 android-17.0.0_rXX)。
- 用户当前工作区仍是 AOSP 14(android-14.0.0_rXX / GKI android14-6.1),要深扒 17 需另 checkout 分支。
- 硬核变更点(Framework 向):
  1. 大屏(sw>600dp)移除方向/尺寸限制 opt-out:`screenOrientation`/`setRequestedOrientation()` 相关值、`resizeableActivity`/`minAspectRatio`/`maxAspectRatio` 被忽略。豁免:sw<600dp、游戏(appCategory=game)、用户系统设置 opt-in。
  2. config change 默认不再重启 Activity:`CONFIG_KEYBOARD`/`KEYBOARD_HIDDEN`/`NAVIGATION`/`UI_MODE`(仅 desk)/`TOUCHSCREEN`/`COLOR_MODE` 仅走 onConfigurationChanged;新增 manifest `android:recreateOnConfigChanges` opt-in 恢复旧 restart 行为。
  3. AppFunctions:平台 API + Jetpack 库(alpha),`@AppFunction` 暴露 app 能力为 on-device MCP 工具,供 Gemini 等 agent 调用;关联 AppFunctionsManager 系统服务。
  4. Profiling 异常检测(Beta4):`ProfilingManager`+`ProfilingTrigger.TRIGGER_TYPE_ANOMALY`,在 OOM kill 前回调,提供 heap dump / binder 栈采样。
  5. Keystore 后量子密码(Beta4):ML-DSA-65/87,经 JCA(AndroidKeyStore)。
  6. 其他:Beta3 起 OpenJDK 25/21 API、VPN app exclusion(`ACTION_VPN_APP_EXCLUSION_SETTINGS`)、重设计录屏工具栏、窗口固定层 `AppTask.WINDOWING_LAYER_REQUEST_GRANTED`。
- 结论:用户关注点从 AOSP 14 扩展到 Android 17。重点落地点在 frameworks/base 的 ActivityManager/ActivityTaskManager、AppFunctions 服务、ProfilingManager、keystore2。
