# 2026-07-14

- 讲解 Android Framework 各层如何串联：kernel drivers / HAL / binder / AMS / WMS / IMS。
  核心结论：
  - Binder 是控制平面，只传指令 + binder 对象句柄，不传大块数据（图形 buffer 走 BufferQueue/dma-buf，输入走 InputChannel/socketpair）。
  - AMS/WMS/IMS 同跑在 system_server 进程内，互相直接 Java/JNI 调用，不跨 Binder。
  - Binder 真正跨进程处：App↔system_server、system_server↔SurfaceFlinger/CameraService 等 native 进程、native↔HAL(HIDL/AIDL)。
  - HAL 往下对 kernel 用 open/ioctl/mmap（v4l2、DRM/KMS、evdev），binder 驱动本身即 /dev/binder。
  - 端到端示例：触摸→IMS→View → startActivity→AMS→Zygote fork→WMS+SurfaceFlinger→渲染→HWC→DRM。
- 进一步给出 startActivity 完整代码调用链（含 AOSP 文件路径/方法名）：
  App Activity.startActivity → Instrumentation.execStartActivity → IActivityManager proxy transact →
  Binder 驱动(binder_ioctl/binder_thread_write/binder_transaction/copy_from_user 进 target mmap) →
  AMS.startActivity → ActivityStarter → ActivityStackSupervisor.startSpecificActivity →
  ProcessList.startProcessLocked → ZygoteProcess(socket /dev/socket/zygote) → fork →
  ActivityThread.main/attach → AMS.attachApplication → realStartActivityLocked →
  ApplicationThread.scheduleTransaction → TransactionExecutor → handleLaunchActivity → onCreate；
  显示侧 ViewRootImpl.setView → IWindowSession.addToDisplay → WMS.addWindow →
  SurfaceSession(native) → SurfaceComposerClient(Binder) → SurfaceFlinger.createLayer →
  HWComposer(HAL) → drmModeAtomicCommit(/dev/dri/card0) → 面板。
  输入侧：Kernel evdev /dev/input/eventX → EventHub → InputReader → InputDispatcher(IMS 封装) →
  InputChannel(socket) → App View.onTouchEvent。
  边界总结：Binder 仅搬命令+句柄；数据走 BufferQueue/dma-buf/InputChannel；AMS/WMS/IMS 同进程直接调用。
- 补充 boot 启动链代码流程：init(PID1) → zygote → system_server → launcher → app。
  - init: system/core/init/{main.cpp,first_stage_init.cpp,selinux.cpp,init.cpp} → SecondStageMain →
    LoadBootScripts 解析 init.zygote64.rc → Service::Start() (service.cpp) fork+execve /system/bin/app_process64；
    rc 里 `socket zygote` 创建 /dev/socket/zygote。
  - Zygote: app_main.cpp main → AppRuntime.start → AndroidRuntime::start(JNI_CreateJavaVM) →
    ZygoteInit.main: preload()/ZygoteServer(LocalServerSocket "zygote")/forkSystemServer()/runSelectLoop()；
    forkSystemServer 经 Zygote.forkSystemServer(native com_android_internal_os_Zygote) → invokeStaticMain(SystemServer)。
  - system_server: SystemServer.run → startBootstrapServices(AMS) → systemReady →
    startHomeOnAllDisplays → startHomeActivity(HOME intent) → Launcher(普通 app)。
  - App 启动：Launcher.startActivity → Binder AMS → ProcessList.startProcessLocked → ZygoteProcess.start →
    openZygoteSocketIfNeeded(/dev/socket/zygote) → ZygoteConnection.processOneCommand → forkAndSpecialize →
    ActivityThread.main → attachApplication → onCreate。
  关键：system_server 与所有 App 都是 Zygote 的 fork 子孙，共享 preload（COW）；Launcher 无特权。
