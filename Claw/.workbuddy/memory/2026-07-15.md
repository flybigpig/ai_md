# 2026-07-15

- 讲解 Binder 内核驱动核心代码注释流程（drivers/android/binder.c + binder_alloc.c）。
  关键点：
  - 一次拷贝本质：发送方 copy_from_user 写入「目标进程 mmap 区对应的共享物理页」，接收方直接读自己 mmap VA，零拷贝；
    copy_to_user 只在 BR_TRANSACTION/BR_REPLY 时拷贝几十字节的描述头 binder_transaction_data，不拷 payload。
  - 主链路：binder_ioctl(BINDER_WRITE_READ) → binder_ioctl_write_read → binder_thread_write(解析 BC_TRANSACTION)
    → binder_transaction（找 target_node: handle→binder_ref→binder_node→proc；binder_alloc_new_buf；copy_from_user；
    flat_binder_object 翻译 binder_translate_binder/translate_handle；enqueue_work + wakeup）→ 目标 binder_thread_read 返回 BR_TRANSACTION。
  - 回包：BC_REPLY → binder_transaction(reply=true) 回原 sender_thread。
  - 每个进程 mmap 自己的 binder_buffer 接收区（binder_mmap → binder_alloc_mmap_handler），所以双向都是一次拷贝。
  - flat_binder_object：跨进程传实体变 handle（fp->type=BINDER_TYPE_HANDLE, fp->handle=ref->desc），同进程保留指针；
    offsets 数组以相对 buffer 的偏移存储，绕过双方 VA 不同。
